# ระบบบริหารงานพัสดุและครุภัณฑ์ โรงพยาบาลหนองจิก (MOPH Government Asset Management)

ระบบบริหารจัดการครุภัณฑ์ภาครัฐตาม **ระเบียบกระทรวงการคลังว่าด้วยการจัดซื้อจัดจ้างและการบริหารพัสดุภาครัฐ พ.ศ. 2560**, มาตรฐานบัญชีภาครัฐ (กรมบัญชีกลาง / สตง.) และเกณฑ์คุณภาพโรงพยาบาล (HA)

## ฟีเจอร์หลัก
- **ทะเบียนคุมทรัพย์สิน (แบบ ผท.)**: ฟิลด์ครบตามมาตรฐานราชการ (แหล่งเงิน, สัญญา, ผู้ขาย, S/N, สถานที่ตั้ง, ผู้รับผิดชอบ), รันรหัสครุภัณฑ์ 13 หลักอัตโนมัติ, คำนวณค่าเสื่อมราคาและมูลค่าสุทธิ (NBV), และ Asset Movement Timeline
- **ระบบความปลอดภัย RBAC 5 บทบาท & Audit Log**: รองรับ Firebase Authentication (Email/Password) + โหมด Local Fallback พร้อมบันทึกประวัติการใช้งาน (Audit Trail) และกฎความปลอดภัย `firestore.rules` / `storage.rules`
- **การตรวจสอบพัสดุประจำปี (ข้อ 213)**: สแกน QR ตรวจนับแบบ Real-time, แนบภาพถ่ายหลักฐาน, กระทบยอด, และพิมพ์บันทึกข้อความเสนอผู้อำนวยการ
- **ระบบจำหน่ายพัสดุภาครัฐ (ข้อ 215–218)**: คัดกรองรายการรอจำหน่ายอัตโนมัติ, Workflow 4 ขั้นตอนครบ 5 วิธีตามระเบียบฯ, ลงจ่ายแบบ Soft Disposal เก็บประวัติถาวร
- **แบบฟอร์มราชการ A4**: พิมพ์แบบ ผท., ใบโอนย้าย/ใบยืม-คืน, บันทึกข้อความรายงานผลตรวจประจำปี, และแบบขออนุมัติจำหน่ายพัสดุ
- **งานซ่อมบำรุงและเครื่องมือแพทย์ (HA)**: บันทึกต้นทุนค่าซ่อมสะสม + แจ้งเตือนไม่คุ้มซ่อม (≥50% หรือ ≥3 ครั้ง/ปี), ตารางแผน PM/Calibration เครื่องมือแพทย์, และแจ้งเตือนยืมเกินกำหนด

## การเปิดใช้งานบน GitHub Pages
1. ไปที่ **Settings → Pages** ของ Repository บน GitHub
2. ในหัวข้อ **Build and deployment → Source** เลือก **GitHub Actions**
3. ทุกครั้งที่ push โค้ดขึ้น branch `main` หรือ `master` ระบบจะรัน `npm test` และ Deploy ขึ้น GitHub Pages อัตโนมัติ (`.github/workflows/deploy-pages.yml`)
4. *(สำคัญสำหรับ Firebase Auth)*: เพิ่มโดเมน `<username>.github.io` ใน **Firebase Console → Authentication → Settings → Authorized domains**
